# Galette Auto plugin

[![GitHub license](https://img.shields.io/github/license/galette-plugins/plugin-auto)](https://github.com/galette-plugins/plugin-auto/blob/master/COPYING)
[![Maintained by the Galette core team](https://img.shields.io/badge/maintained_by-Galette_core_team-ffb619?style=for-the-badge&logo=php&logoColor=white)](https://galette.eu)

### English

A [Galette](https://galette.eu) plugin to manage cars and owners for automobile clubs.

This plugin is developed and maintained by the **Galette core team**, along with Galette itself — unlike most of the plugins hosted in this organization, which are community-maintained.

* website: https://galette-plugins.github.io/plugin-auto/
* bugs and features: https://bugs.galette.eu/projects/galette-plugin-auto
* mailing lists:
  * users: https://lists.mailman3.com/postorius/lists/galette-users.mailman3.com/
  * developers: https://lists.mailman3.com/postorius/lists/galette-devel.mailman3.com/
* documentation: https://galette-plugins.github.io/plugin-auto/documentation.html

To use Galette Auto plugin, you'll need a reliable Galette version, and of course the plugin itself by either:

* download latest version available from the [releases page](https://github.com/galette-plugins/plugin-auto/releases)
* use [Galette Auto plugin source code from repository](https://github.com/galette-plugins/plugin-auto), this solution requires some technical skills

### Français

Un plugin [Galette](https://galette.eu) pour gérer voitures et propriétaires de clubs automobile.

Ce plugin est développé et maintenu par l'**équipe Galette**, comme Galette lui-même — contrairement à la plupart des plugins hébergés dans cette organisation, qui sont maintenus par la communauté.

* site web : https://galette-plugins.github.io/plugin-auto/
* bogues et fonctionnalités : https://bugs.galette.eu/projects/galette-plugin-auto
* listes de diffusion :
  * utilisateurs : https://lists.mailman3.com/postorius/lists/galette-users.mailman3.com/
  * développeurs : https://lists.mailman3.com/postorius/lists/galette-devel.mailman3.com/
* documentation : https://galette-plugins.github.io/plugin-auto/fr/documentation.html

Pour utiliser le plugin Auto pour Galette, vous aurez besoin d'une version adéquate de Galette, ainsi que du plugin lui-même :

* télécharger la dernière version depuis la [page des versions](https://github.com/galette-plugins/plugin-auto/releases)
* utiliser [le code source du plugin Auto pour Galette depuis le dépôt](https://github.com/galette-plugins/plugin-auto), cette solution requiert quelques compétences techniques
